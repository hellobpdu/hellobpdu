## Current work

### Deep32

A retrieval system for network and security questions. It answers from a local corpus of RFCs, vendor documentation and security advisories, checks each answer against the retrieved text, and flags places where sources disagree. Multi-node and locally hosted. It uses Model Context Protocol for tooling and large language models, including Claude Mythos, for reasoning. Not yet released.

### Protocol accuracy

Testing model answers against the RFCs and vendor documentation for BGP, OSPF, EIGRP, IKEv2 and IPsec, group-key VPNs, and 802.1X with EAP-TLS. The focus is on cases where an implementation differs from its standard.

### Defensive security

Analysis of published vulnerabilities in routing and VPN platforms, and the hardening that follows from them. This work runs under Defense Access in Anthropic's Cyber Verification Program, approved in 2026.
